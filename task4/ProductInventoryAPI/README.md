# Product Inventory API (Lab Task 04)

NestJS + TypeORM + PostgreSQL - single entity CRUD.

## Run
1. Install Node.js (v18+) and PostgreSQL.
2. Create DB: `CREATE DATABASE product_inventory_db;`
3. Edit `.env` and put your real PostgreSQL password in `DB_PASSWORD`.
4. `npm install`
5. `npm run start:dev`
6. API runs at http://localhost:3000/products - test using `requests.http` or Postman.
